# Web 終端機

Web 終端機從管理後台連線到管理員設定的 SSH 目標，適合查看狀態、執行短指令與緊急除錯。它不會直接開啟 fn-knock 主機的本機 Shell；只要 SSH 服務允許互動式 PTY，目標可以是 Linux、macOS 或 Windows。

所有 fn-knock 發行平台都提供此功能。fn-knock 執行環境必須能連到目標的 SSH 主機與連接埠；Web 終端機不會自動修改 Docker 連接埠、OpenWrt 防火牆或其他平台網路規則。

## 權限邊界

指令以設定的 SSH 使用者權限在遠端執行。應只向可信管理員開放管理後台，優先使用權限受限的專用帳號與私鑰，並透過獨立可信管道核對主機指紋。修改套件、設定或防火牆前先備份；Web 終端機不能取代 SSH 安全策略、稽核與最小權限管理。

## 新增 SSH 目標

進入 `Web 終端機`，點選 `新增 SSH 目標`，填寫名稱、主機、連接埠、使用者名稱與驗證方式。驗證支援密碼或 OpenSSH 私鑰，加密私鑰也可填入口令。

憑證會在 fn-knock 本機加密儲存。首次測試時，系統先取得伺服器主機金鑰並顯示演算法與指紋；明確確認後才會傳送驗證資料。請在伺服器主控台、已知 SSH 用戶端或管理員記錄中核對，不要只依賴頁面顯示。

確認指紋並通過連線測試後即可儲存。主機、連接埠、使用者、驗證方式或受信任金鑰變更時，既有活動工作階段可能必須先結束；頁面會列出影響範圍。

## 目標與工作階段

每個目標可建立多個獨立 Shell 工作階段。終端服務持續執行時，重新整理頁面或短暫斷線不會立即結束遠端 Shell；fn-knock 服務重啟、遠端 Shell 退出或管理員結束後無法復原。

頁面可新增、切換、重新命名與重新連線工作階段，也可最大化、調整字型、複製、貼上、全選、原樣傳送文字，以及查看 DNS 解析、金鑰驗證、身分驗證與 PTY 申請等連線階段。

同一工作階段一次只有一個瀏覽器能輸入。其他瀏覽器可唯讀查看，並在需要時選擇 `接管控制`。刪除目標會移除加密憑證；若仍有活動工作階段，必須二次確認並先結束，且無法復原。

## 行動裝置操作

窄螢幕會顯示控制鍵、修飾鍵、方向鍵與字型大小工具列。瀏覽器無法讀取剪貼簿時，使用 `傳送到終端機` 對話框手動貼上。長指令、互動式編輯、長時間工作與檔案傳輸仍建議使用本機 SSH 用戶端。

## 稽核與憑證

事件中心會記錄目標新增、修改與刪除、指紋確認、連線測試、工作階段建立、結束、退出與遺失。它不記錄每條輸入指令；指令層級稽核仍需在 SSH 目標系統設定。

憑證與私鑰是敏感資料。匯出應用備份、搬移資料目錄或分享診斷資料時應按憑證檔案保護；刪除目標後，也要在伺服器撤銷不再需要的帳號或公鑰。

## 疑難排解

- 無法取得指紋：確認 fn-knock 能解析主機並連到 SSH 連接埠；指紋不符時停止驗證，先檢查 DNS、主機重裝或金鑰輪替紀錄。
- 連線測試失敗：核對使用者、密碼、私鑰格式與口令，並確認 SSH 服務允許該驗證方式及互動式 PTY。
- 工作階段無法復原：檢查連線階段與錯誤；遠端 Shell、SSH 鏈路或終端服務可能已結束，確認可達後建立新工作階段。
- 只能查看：另一個瀏覽器正在控制同一工作階段；確認不會打斷操作後接管，或另建工作階段。
