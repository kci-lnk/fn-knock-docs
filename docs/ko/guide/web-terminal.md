# 웹 터미널

웹 터미널은 관리자가 설정한 SSH 대상에 관리 패널에서 연결합니다. 상태 확인, 짧은 명령, 긴급 문제 해결에 적합합니다. fn-knock 호스트의 로컬 Shell을 직접 열지 않습니다. SSH 서버가 대화형 PTY를 제공하면 Linux, macOS 또는 Windows를 대상으로 사용할 수 있습니다.

모든 fn-knock 배포 패키지에서 사용할 수 있습니다. fn-knock 실행 환경에서 대상 SSH 호스트와 포트에 연결할 수 있어야 하며 Docker 포트 게시, OpenWrt 방화벽 또는 다른 플랫폼 네트워크 규칙은 자동으로 변경하지 않습니다.

## 권한 경계

명령은 설정된 SSH 사용자의 원격 권한으로 실행됩니다. 관리 패널은 신뢰할 수 있는 관리자에게만 허용하고, 권한이 제한된 전용 계정과 개인 키 인증을 우선 사용하며, 독립된 신뢰 경로로 호스트 지문을 확인하십시오. 패키지, 설정 또는 방화벽 변경 전에는 백업해야 합니다. 웹 터미널은 SSH 보안 강화, 감사 또는 최소 권한 관리를 대신하지 않습니다.

## SSH 대상 추가

`웹 터미널`에서 `SSH 대상 추가`를 선택하고 이름, 호스트, 포트, 사용자 이름, 인증 방식을 입력합니다. 비밀번호와 OpenSSH 개인 키를 지원하며 암호화된 키의 암호도 입력할 수 있습니다.

자격 증명은 fn-knock 호스트에 암호화되어 저장됩니다. 첫 테스트에서는 서버 호스트 키 알고리즘과 지문을 표시하며 명시적으로 확인한 뒤에만 인증 정보를 보냅니다. 서버 콘솔, 이미 신뢰하는 SSH 클라이언트 또는 관리자의 기록과 비교하고 화면에 표시되었다는 이유만으로 신뢰하지 마십시오.

지문 확인과 연결 테스트가 성공한 뒤 저장합니다. 호스트, 포트, 사용자, 인증 방식 또는 신뢰한 키를 변경하면 활성 세션을 종료해야 할 수 있으며 저장 전에 영향받는 세션을 표시합니다.

## 대상과 세션

각 대상에 여러 독립 Shell 세션을 만들 수 있습니다. 터미널 서비스가 실행되는 동안에는 페이지 새로 고침이나 짧은 네트워크 끊김으로 원격 Shell이 즉시 끝나지 않습니다. fn-knock 서비스 재시작, 원격 Shell 종료 또는 관리자 종료 뒤에는 복구할 수 없습니다.

세션 생성, 전환, 이름 변경, 재연결, 최대화, 글꼴 크기 변경, 복사, 붙여넣기, 전체 선택과 텍스트 원문 전송을 지원합니다. 이름 확인, 호스트 키 검증, 인증, PTY 요청 등 연결 단계도 볼 수 있습니다.

한 세션에는 한 번에 한 브라우저만 입력을 제어합니다. 다른 브라우저는 읽기 전용으로 출력만 보고 필요하면 `제어권 가져오기`를 선택할 수 있습니다. 대상을 삭제하면 암호화된 자격 증명도 제거됩니다. 활성 세션이 있으면 다시 확인한 뒤 먼저 종료하며 되돌릴 수 없습니다.

## 모바일 사용

좁은 화면에는 제어 키, 수정 키, 탐색 키와 글꼴 도구가 표시됩니다. 브라우저가 클립보드를 읽지 못하면 `터미널로 보내기` 대화 상자에 직접 붙여넣습니다. 긴 명령, 대화형 편집, 장시간 작업과 파일 전송에는 로컬 SSH 클라이언트를 사용하십시오.

## 감사와 자격 증명

이벤트 센터는 대상 생성·수정·삭제, 지문 확인, 연결 테스트, 세션 생성·종료·원격 종료·연결 손실을 기록합니다. 입력한 모든 명령을 기록하지는 않으므로 명령 수준 감사는 SSH 대상 시스템에서 설정해야 합니다.

자격 증명과 개인 키는 민감한 데이터입니다. 앱 내보내기, 데이터 디렉터리 이전, 진단 자료를 자격 증명 파일처럼 보호하고, 대상을 삭제한 뒤에는 서버에서 불필요한 계정이나 공개 키도 폐기하십시오.

## 문제 해결

- 지문을 가져오지 못함: fn-knock에서 이름을 확인하고 SSH 포트에 도달할 수 있는지 검사합니다. 지문이 다르면 인증을 중단하고 DNS, 재설치, 키 교체 기록을 확인합니다.
- 연결 테스트 실패: 사용자, 비밀번호 또는 키 형식, 키 암호, 허용된 인증 방식과 대화형 PTY 지원을 확인합니다.
- 세션 복구 실패: 연결 단계와 오류를 확인합니다. 원격 Shell, SSH 링크 또는 터미널 서비스가 끝났다면 연결을 복구한 뒤 새 세션을 만듭니다.
- 읽기 전용: 다른 브라우저가 세션을 제어 중입니다. 작업을 방해하지 않을 때만 제어권을 가져오거나 별도 세션을 만듭니다.
