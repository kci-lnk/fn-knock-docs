# 게이트웨이 포털

포털은 로그인된 게이트웨이 페이지에 표시되는 서비스 탐색 도구입니다. 탐색 가능한 서비스 Host와 경로 매핑 사이를 간편하게 전환하고 현재 세션에서 로그아웃할 수 있습니다. 매핑 권한, 허용 목록 또는 인증 요구 사항을 변경하지는 않습니다.

![포털을 펼친 서비스 목록. 서비스 아이콘, 이름 및 로그아웃 항목이 표시되어 있습니다.](/screen-gobtn.webp)

페이지 오른쪽 아래의 플로팅 버튼을 누르면 포털이 펼쳐집니다. 현재 계정으로 접근할 수 있는 서비스로 전환하거나 현재 로그인에서 로그아웃할 수 있습니다.

`시스템 설정 → 게이트웨이 → 포털 설정`에서는 포털 표시 여부, 서비스 제목 또는 도메인 표시, 서비스 아이콘 표시 여부, 아이콘을 네 모서리에 고정하거나 자유롭게 드래그하는 방식을 설정할 수 있습니다.

| 설정 | 페이지 동작 |
| --- | --- |
| `포털 활성화` | 활성화하면 로그인한 사용자가 서비스 서브도메인에 접속할 때 서비스 전환 도구 모음 표시 |
| `포털 표시` | 도메인 또는 사이트 제목 선택. 제목이 비어 있으면 도메인 표시 |
| `포털 아이콘 드래그 위치` | `네 모서리`는 아이콘을 모서리에 고정하고 `자유`는 뷰포트 안의 원하는 위치에 배치 |
| `서비스 아이콘 표시` | 아이콘을 이미 수집한 엔드포인트에만 표시하며 아이콘이 없는 항목은 빈 공간을 남기지 않음 |

이 옵션은 누르는 즉시 저장되고 동기화되므로 게이트웨이 페이지로 돌아가 전체 저장을 다시 실행할 필요가 없습니다. 표시 방식을 바꿔도 로그인 세션은 종료되지 않습니다.

서비스가 포털에 표시되는지는 현재 라우트 방식과 매핑 상태에 따라 달라집니다. Host별 ‘포털 표시’ 설정으로 개별 항목을 숨길 수 있지만 현재 경로 매핑에는 이에 해당하는 개별 숨김 스위치가 없습니다. Host를 숨기면 탐색 목록에만 영향을 주며 서비스가 비공개 또는 공개 상태로 바뀌지는 않습니다.

설정 후 보호된 서비스 Host에서 로그인하여 도구 모음, 제목, 아이콘 및 드래그 방식이 예상대로인지 확인합니다. 포털 자체는 권한을 부여하지 않습니다. 특정 Host가 목록에 표시되어도 제한된 자격 증명의 실제 접근 가능 여부는 요청 시 서비스 범위에 따라 판단됩니다.

표시가 올바르지 않다면 다음 순서로 확인합니다.

1. 전역 포털이 활성화되어 있고 현재 Host에서 ‘포털 표시’를 끄지 않았는지 확인합니다.
2. 현재 요청이 로그인된 상태이고 Host 엔드포인트를 지원하는 라우트 방식을 사용하는지 확인합니다.
3. 매핑의 사이트 제목을 확인합니다. 제목 표시 모드에서 제목이 비어 있으면 도메인이 표시됩니다.
4. 아이콘이 없다면 서비스에 다시 접속하여 게이트웨이가 아이콘을 수집하도록 합니다. 계속 아이콘이 없는 엔드포인트는 공간을 차지하지 않습니다.
5. 자격 증명의 서비스 범위와 대조합니다. 목록에 엔드포인트가 보인다고 해서 접근 권한이 있는 것은 아닙니다.
