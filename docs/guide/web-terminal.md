# Web 终端

Web 终端在管理后台中提供受控的宿主机 shell 会话，适合查看状态、执行短命令和紧急排障。它不是日常开发环境，也不应替代 SSH 密钥、审计和最小权限管理。

该功能依赖 `tmux` 保存可恢复会话。当前支持飞牛 fnOS FPK 和通用 Linux；Docker、OpenWrt、群晖 DSM 7 SPK 和 Windows x86_64 不提供 Web 终端入口。

## 权限边界

终端命令使用 fn-knock 服务进程的系统权限执行。服务以 root 运行时，终端也可能拥有 root 权限，错误命令可直接修改系统、应用数据和网络配置。

- 只向可信管理员开放管理面板；
- 为管理面板配置独立的访问范围和强认证；
- 不在终端输入会被浏览器历史、剪贴板或录屏留存的长期密钥；
- 修改配置文件、软件包或防火墙前先备份；
- 不把 Web 终端作为公网 SSH 的替代入口。

## tmux 环境

在 `系统设置 → 终端` 查看 tmux 状态与版本。状态包括未安装、安装中、已安装和错误。

- 未安装时可从页面启动安装；
- 安装过程会显示进度，完成后刷新状态；
- 安装失败时可查看错误并重新安装；
- tmux 未就绪时不能创建终端会话。

安装操作需要部署环境具备相应的软件包管理和网络条件。页面持续停在安装中或报错时，应检查后台日志、软件源和磁盘空间。

## 终端设置

| 设置 | 默认值与范围 | 说明 |
| --- | --- | --- |
| 启用 Web 终端 | 默认关闭 | 开启后显示侧边导航并允许创建会话 |
| 最大会话数 | 默认 3，范围 1～12 | 已达到上限时不能继续创建 |
| 空闲清理时间 | 默认 86400 秒，范围 60～604800 秒 | 即 1 分钟到 7 天；到期的空闲会话由后台清理 |

空闲清理时间针对服务器上的 tmux 会话，不是浏览器登录会话时长。保存设置后返回 Web 终端页验证导航和运行状态。

## 会话行为

首次打开页面时，系统会读取已有会话，并优先恢复当前浏览器最近使用的会话；没有会话时会尝试创建默认会话。页面提供：

- 新建会话；
- 在多个会话标签间切换；
- 重命名当前会话；
- 重新附着到断开的会话；
- 向终端原样发送一段文本；
- 结束并永久删除当前会话；
- 最大化、调整字体、复制、粘贴和全选。

浏览器通过 HTTP 长轮询接收终端输出。网络短暂断开后可重新连接；页面刷新或关闭浏览器只会解除当前附着，不会立即结束底层 tmux 会话。需要彻底停止进程和删除会话时，执行 shell 退出或点击“结束会话”。

结束会话不可恢复。会话中仍在运行的命令也会随该 tmux 会话终止。

## 移动端操作

窄屏设备会显示快捷工具栏，提供常用控制键、修饰键、方向与导航键以及字号调节。浏览器不允许直接读取剪贴板时，页面会打开“发送到终端”对话框，由用户手动粘贴后发送。

手机浏览器适合短时排障；长命令、交互式编辑、持续任务和文件传输更适合使用本地 SSH 客户端。

## 排查

### 入口不显示

确认部署平台支持终端能力、tmux 已安装、功能已经保存为启用，并重新加载管理后台配置。

### 页面提示当前不可用

运行状态会给出阻断原因，常见情况包括功能未开启、tmux 正在安装、tmux 缺失或安装错误。先在 `系统设置 → 终端` 修复运行环境。

### 无法新建会话

检查当前会话数是否达到上限，并确认旧会话是否仍在运行。必要时结束不再使用的会话。

### 会话无法恢复

会话可能已超过空闲清理时间、被其他管理员结束、因宿主机重启消失，或 fn-knock 无法重新附着 tmux。刷新运行状态后再创建新会话。

### 有连接但没有输出

使用“重连”重新附着；仍无输出时检查浏览器网络请求和后台日志。反向代理对长轮询设置过短的超时也可能造成反复断开。
