# 网关传送门

传送门是在已登录的网关页面中显示的服务导航组件。它方便在可导航的业务 Host 和路径映射之间切换，也提供退出当前会话的入口；它不改变映射权限、白名单或认证要求。

![传送门展开后的服务列表，包含应用图标、服务名称和退出登录入口](/screen-gobtn.webp)

点击页面右下角的悬浮按钮，即可展开传送门，在当前账号有权访问的服务之间切换，或退出当前登录。

在 `系统设置 → 网关 → 传送门` 可以控制是否显示、显示服务标题还是域名、是否显示应用图标，以及图标采用四角停靠或自由拖动。

| 设置 | 页面行为 |
| --- | --- |
| `启用传送门` | 开启后，已登录用户访问业务子域时显示切换应用的工具栏 |
| `传送门显示` | 选择域名或站点标题；标题为空时回退为域名 |
| `传送门图标拖拽位置` | `四个角` 会把图标吸附到角落，`自由` 允许停留在视口内任意位置 |
| `显示应用图标` | 对已有自动采集或自定义图标的入口展示；没有图标的入口不会保留空位 |

这些选项点击后立即保存并同步，不需要再回到网关页点击统一保存。修改显示风格不会结束登录会话。

服务是否出现在传送门中，取决于当前路由方式和映射状态。Host 可通过自身的“显示传送门”设置单独隐藏；路径映射目前没有对应的单项隐藏开关。隐藏 Host 只影响导航展示，不会把服务变成私有或公开。

配置后从受保护的业务 Host 登录，确认工具栏、标题、图标和拖动方式符合预期。传送门本身不授予权限；即使列表中出现某个 Host，受限凭据能否访问仍以实际请求的服务范围判断。

显示不正确时按以下顺序检查：

1. 确认全局传送门已启用，当前 Host 未关闭“显示传送门”。
2. 确认当前请求已经登录，并处于支持 Host 入口的路由方式。
3. 检查映射的站点标题；标题模式下空标题会显示域名。
4. 没有图标时，在 `子域映射` 中编辑对应 Host，打开 `应用图标` 后重新采集或上传自定义图片；仍无图标的入口不会占位。
5. 对照凭据服务范围；能在列表中看到入口不等于具备访问权。
