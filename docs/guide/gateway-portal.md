# 网关传送门

传送门是在已登录的网关页面中显示的服务导航组件。它方便在可导航的业务 Host 和路径映射之间切换，也提供退出当前会话的入口；它不改变映射权限、白名单或认证要求。

![传送门展开后的服务列表，包含应用图标、服务名称和退出登录入口](/screen-gobtn.webp)

点击页面上的悬浮按钮，即可打开传送门，在当前账号有权访问的服务之间切换，或退出当前登录。

在 `系统设置 → 网关 → 传送门` 可以选择传送门版本，并控制是否显示、显示服务标题还是域名、是否显示应用图标，以及图标采用四角停靠或自由拖动。

| 设置 | 页面行为 |
| --- | --- |
| `启用传送门` | 开启后，已登录用户访问业务子域时显示切换应用的工具栏 |
| `传送门版本` | `v1 经典` 使用经典工具栏；`v2 启动台` 使用全屏毛玻璃启动台，可随时切换 |
| `传送门显示` | 选择域名或站点标题；标题为空时回退为域名 |
| `传送门图标拖拽位置` | `四个角` 会把图标吸附到角落，`自由` 允许停留在视口内任意位置 |
| `显示应用图标` | 展示自动采集或自定义图标；v1 不为无图标入口保留空位，v2 会生成占位图标 |
| `显示远程唤醒快捷入口` | WOL 功能开启时显示；允许有权限的已登录账号打开内置设备唤醒页 |

这些选项点击后立即保存并同步，不需要再回到网关页点击统一保存。切换版本或修改显示风格不会结束登录会话。

服务是否出现在传送门中，取决于当前路由方式和映射状态。Host 可通过自身的“显示传送门”设置单独隐藏；路径映射目前没有对应的单项隐藏开关。隐藏 Host 只影响导航展示，不会把服务变成私有或公开。

子域映射启用 `分组视图` 时，传送门和内置 `/__select__` 选择页会使用相同的分组名称、分组顺序与 Host 顺序；切回列表视图后，两处会恢复为扁平列表，但已保存的分组归属不会丢失。分组只改变导航结构，凭据服务范围和每条映射的认证设置仍照常执行。

配置后从受保护的业务 Host 登录，确认所选版本、标题、图标和拖动方式符合预期。传送门本身不授予权限；即使列表中出现某个 Host，受限凭据能否访问仍以实际请求的服务范围判断。

远程唤醒快捷入口默认开启，但只在 `系统设置 → 功能 → 远程唤醒` 已启用时实际显示。内置 `/__wol__` 页面只列出已启用设备的名称和简化状态；使用自定义服务范围的凭据还必须在 `认证配置 → 权限` 中勾选 `内置远程唤醒页面`。关闭快捷入口会同时禁止通过公共认证 API 使用该页面，不影响管理员或第三方平台触发唤醒。完整配置见[远程唤醒](/guide/wake-on-lan)。

显示不正确时按以下顺序检查：

1. 确认全局传送门已启用，当前 Host 未关闭“显示传送门”。
2. 确认当前请求已经登录，并处于支持 Host 入口的路由方式。
3. 检查映射的站点标题；标题模式下空标题会显示域名。
4. 没有图标时，在 `子域映射` 中编辑对应 Host，打开 `应用图标` 后重新采集或上传自定义图片；v2 会先显示生成的占位图标。
5. 分组或顺序不正确时，确认子域映射当前是否为 `分组视图`，并在 `管理分组` 中检查顺序。
6. 对照凭据服务范围；能在列表中看到入口不等于具备访问权。
7. 远程唤醒入口缺失时，检查 WOL 功能、传送门快捷入口和当前凭据是否包含内置 WOL 页面。
