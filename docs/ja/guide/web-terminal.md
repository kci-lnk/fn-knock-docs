# Web ターミナル

Web ターミナルは、管理者が設定した SSH ターゲットへ管理画面から接続します。状態確認、短いコマンド、緊急時の調査向けです。fn-knock ホストのローカル Shell を直接開く機能ではありません。SSH サーバーが対話型 PTY を提供すれば、Linux、macOS、Windows を接続先にできます。

この機能はすべての fn-knock 配布パッケージで利用できます。fn-knock の実行環境から SSH ホストとポートへ到達できる必要があり、Docker のポート公開、OpenWrt のファイアウォール、その他のネットワーク設定は自動変更されません。

## 権限境界

コマンドは設定した SSH ユーザーのリモート権限で実行されます。管理画面を信頼できる管理者だけに限定し、権限を絞った専用ユーザーと秘密鍵認証を優先してください。ホスト指紋は独立した信頼経路で照合し、パッケージ、設定、ファイアウォールの変更前にはバックアップします。Web ターミナルは SSH の堅牢化、監査、最小権限の代替ではありません。

## SSH ターゲットを追加する

`Web ターミナル` で `SSH ターゲットを追加` を選び、名前、ホスト、ポート、ユーザー名、認証方式を入力します。パスワードまたは OpenSSH 秘密鍵に対応し、暗号化鍵のパスフレーズも指定できます。

認証情報は fn-knock ホスト上で暗号化保存されます。最初のテストではサーバーのホスト鍵と指紋を表示し、明示的に確認するまで認証情報を送信しません。サーバーコンソール、既知の SSH クライアント、管理者の記録と照合し、画面に表示されたという理由だけで信頼しないでください。

指紋の確認と接続テスト後に保存します。ホスト、ポート、ユーザー、認証方式、信頼済み鍵を変更すると、既存セッションの終了が必要になる場合があり、保存前に影響範囲が表示されます。

## ターゲットとセッション

ターゲットごとに複数の独立した Shell セッションを作成できます。ターミナルサービスの稼働中は、ページ更新や短い切断だけではリモート Shell は終了しません。fn-knock の再起動、リモート Shell の終了、管理者による終了後は復元できません。

セッションの作成、切り替え、名前変更、再接続、最大化、文字サイズ変更、コピー、貼り付け、全選択、テキスト送信が可能です。名前解決、ホスト鍵確認、認証、PTY 要求などの接続段階も確認できます。

1 つのセッションを入力操作できるブラウザーは同時に 1 つです。他のブラウザーは読み取り専用で出力を確認し、必要なら `操作を引き継ぐ` を選べます。ターゲット削除は暗号化認証情報も削除します。実行中セッションがある場合は再確認して先に終了し、元に戻せません。

## モバイル操作

狭い画面には制御キー、修飾キー、移動キー、文字サイズのツールバーが表示されます。ブラウザーがクリップボードを読めない場合は `ターミナルへ送信` ダイアログに手動で貼り付けます。長いコマンド、対話型編集、長時間処理、ファイル転送にはローカル SSH クライアントを使用してください。

## 監査と認証情報

イベントセンターはターゲットの作成・変更・削除、指紋確認、接続テスト、セッションの作成・終了・退出・喪失を記録します。入力した各コマンドは記録しないため、コマンド監査は SSH ターゲット側で設定します。

認証情報と秘密鍵は機密データです。アプリのエクスポート、データディレクトリ移行、診断資料を認証ファイルと同様に保護し、ターゲット削除後は不要なアカウントや公開鍵をサーバー側でも失効させてください。

## トラブルシューティング

- 指紋を取得できない：fn-knock から名前解決と SSH ポート到達性を確認します。不一致なら認証せず、DNS、再構築、鍵ローテーション履歴を調べます。
- 接続テストが失敗する：ユーザー、パスワードまたは鍵形式、パスフレーズ、許可された認証方式、対話型 PTY を確認します。
- セッションを復元できない：接続段階とエラーを確認します。リモート Shell、SSH、ターミナルサービスが終了していれば、到達性を直して新規作成します。
- 読み取り専用：別ブラウザーが操作中です。妨げないことを確認して引き継ぐか、別セッションを作成します。
